# DNA Sequence Analyzer 🧬

A simple Python program for basic DNA sequence analysis.

## Features

- DNA sequence validation
- Nucleotide counting
- DNA complement
- DNA sequence length
- GC content calculation

## Technologies

- Python
- Sets
- Loops
- Conditional statements
- String manipulation

## Example

Input:  

ATGCGTACG  

Output:  

DNA complement: TACGCATGC  

Length of DNA: 9  

A: 2  

G: 3  

C: 2  

T: 2  

GC: 55.55%
